Deploy Omnipolymath on Railway from this repository's `Dockerfile` and use it through the web Control UI. There is no one-click Railway template for Omnipolymath; templates you find there are for other software.

## Deploy from GitHub

<Steps>
  <Step title="Create the service">
    In Railway, create a new project with **Deploy from GitHub repo** and pick your fork of [the repository](https://github.com/krishnashahane/Omnipolymath). Railway builds it from the `Dockerfile`.
  </Step>

  <Step title="Set the start command">
    Under **Settings -> Deploy -> Custom Start Command**, set `node omnipolymath.mjs gateway --allow-unconfigured` so a fresh volume without a config file still starts.
  </Step>

<Step title="Add a volume">
  Attach a volume mounted at `/data` (required for persistent state).
</Step>

  <Step title="Set variables">
    Set the required **Variables** on the service:

    - `OMNIPOLYMATH_GATEWAY_PORT=8080` (required -- must match the port in Public Networking)
    - `OMNIPOLYMATH_GATEWAY_TOKEN` (required; treat as an admin secret)
    - `OMNIPOLYMATH_STATE_DIR=/data/.omnipolymath` (required for persistent state)
    - `OMNIPOLYMATH_WORKSPACE_DIR=/data/workspace` (required for a persistent workspace)

  </Step>

<Step title="Enable public networking">
  Under **Public Networking**, enable **HTTP Proxy** for the service on port `8080`.
</Step>

  <Step title="Connect">
    Find your public URL in **Railway -> your service -> Settings -> Domains** -- either a generated domain (often `https://<something>.up.railway.app`) or your attached custom domain.

    Open the URL and connect using `OMNIPOLYMATH_GATEWAY_TOKEN`; if you switch to password auth, use that password instead.

  </Step>
</Steps>

From the Railway shell, run the read-only deployment preflight:

```bash
omnipolymath doctor --json
```

## What you get

- Hosted Omnipolymath Gateway + Control UI
- Persistent storage via the Railway Volume (`/data`), so `omnipolymath.json`, shared and per-agent SQLite auth stores, channel/provider state, sessions, and workspace survive redeploys

## Connect a channel

Use the Control UI on the service URL or run `omnipolymath onboard` via Railway's shell for channel setup instructions:

- [Discord](/channels/discord)
- [Telegram](/channels/telegram) (fastest -- just a bot token)

## Backups and migration

Export your state, config, auth profiles, and workspace:

```bash
omnipolymath backup create
omnipolymath backup restore <archive.tar.gz> --target <fresh-directory>
```

Restore verifies and extracts into a fresh staging directory; activation is a
separate offline step. See [Restore a full archive](/install/backups#restore-a-full-archive)
for the rollback warnings and activation sequence.
