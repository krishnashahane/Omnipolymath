There is no one-click Northflank template for Omnipolymath. Templates you find there are for other software.

To run Omnipolymath on Northflank, build the image from the repository's `Dockerfile` as your own service:

1. Create a Northflank project and a **combined service** that builds from your fork of [the repository](https://github.com/krishnashahane/Omnipolymath) with its `Dockerfile`.
2. Override the start command with `node omnipolymath.mjs gateway --allow-unconfigured`, so a fresh volume without a config file still starts.
3. Add a persistent volume mounted at `/data`.
4. Set these environment variables:
   - `OMNIPOLYMATH_GATEWAY_PORT=8080`
   - `OMNIPOLYMATH_GATEWAY_TOKEN` (a strong random value)
   - `OMNIPOLYMATH_STATE_DIR=/data/.omnipolymath`
   - `OMNIPOLYMATH_WORKSPACE_DIR=/data/workspace`
5. Expose port `8080` over HTTP, open the service URL and connect with the token.

These are the same settings as the tested [Render Blueprint](/install/render).

From the Northflank shell, run the read-only deployment preflight:

```bash
omnipolymath doctor --json
```

See [Docker](/install/docker) for the container layout and environment variables.
