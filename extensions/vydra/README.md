# Omnipolymath Vydra Provider

Official Omnipolymath provider plugin for Vydra image, video, and speech generation.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/vydra-provider
omnipolymath gateway restart
```

Set `VYDRA_API_KEY`, then configure an image, video, or speech model. See
<https://omnipolymath.vercel.app/docs/providers/vydra> for capability details and examples.
