# Cloudflare Omnipolymath plugin

Official Omnipolymath plugin for Cloudflare R2 storage locations.

## Install

```sh
omnipolymath plugins install @omnipolymath/cloudflare
```

## Docs

See `docs/plugins/cloudflare.md` in the Omnipolymath repository, or the published docs at <https://omnipolymath.vercel.app/docs/plugins/cloudflare>, for bucket setup, credentials, and storage configuration.
