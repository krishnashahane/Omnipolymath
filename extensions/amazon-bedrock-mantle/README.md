# Omnipolymath Amazon Bedrock Mantle Provider

Official Omnipolymath provider plugin for routing Amazon Bedrock Mantle models through OpenAI-compatible provider flows.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/amazon-bedrock-mantle-provider
```

Use this plugin when your Bedrock deployment exposes Mantle-compatible model routing and you want Omnipolymath agents to address those models through the Bedrock Mantle provider.
