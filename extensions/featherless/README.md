# Omnipolymath Featherless AI Provider

Official Omnipolymath provider plugin for Featherless AI's OpenAI-compatible API.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/featherless-provider
omnipolymath gateway restart
```

See <https://omnipolymath.vercel.app/docs/providers/featherless> for setup and configuration.
