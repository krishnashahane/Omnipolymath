# Vercel AI Gateway Omnipolymath provider

Official Omnipolymath provider plugin for Vercel AI Gateway.

## Install

```sh
omnipolymath plugins install @omnipolymath/vercel-ai-gateway-provider
```

## Docs

See `docs/providers/vercel-ai-gateway.md` in the Omnipolymath repository, or the published docs at `https://omnipolymath.vercel.app/docs/providers/vercel-ai-gateway`.
