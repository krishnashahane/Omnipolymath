# Omnipolymath GMI Cloud Provider

Official Omnipolymath provider plugin for hosted GMI Cloud models through an
OpenAI-compatible API.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/gmi-provider
omnipolymath gateway restart
```

Configure a GMI Cloud API key, then select models with refs such as
`gmi/openai/gpt-5.6-sol`.
