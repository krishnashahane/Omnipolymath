# Omnipolymath Cloudflare AI Gateway Provider

Official Omnipolymath provider plugin for Cloudflare AI Gateway.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/cloudflare-ai-gateway-provider
omnipolymath gateway restart
```

See <https://omnipolymath.vercel.app/docs/providers/cloudflare-ai-gateway> for setup and configuration.
