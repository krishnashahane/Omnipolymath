# Omnipolymath Synthetic Provider

Official Omnipolymath provider plugin for Synthetic's hosted Anthropic-compatible
API.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/synthetic-provider
omnipolymath gateway restart
```

Configure `SYNTHETIC_API_KEY`, then select a `synthetic/<model-id>` model.

See https://omnipolymath.vercel.app/docs/providers/synthetic for model and configuration
details.
