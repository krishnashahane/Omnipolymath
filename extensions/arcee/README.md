# Omnipolymath Arcee AI Provider

Official Omnipolymath provider plugin for Arcee AI.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/arcee-provider
omnipolymath gateway restart
```

See <https://omnipolymath.vercel.app/docs/providers/arcee> for setup and configuration.
