# Z.AI Omnipolymath provider

Official Omnipolymath provider plugin for Z.AI.

Video task polling honors the provider's private-network policy even without a
proxy override. Generated video downloads keep their separate asset boundary.

## Install

```sh
omnipolymath plugins install @omnipolymath/zai-provider
```

## Docs

See `docs/providers/zai.md` in the Omnipolymath repository, or the published docs at `https://omnipolymath.vercel.app/docs/providers/zai`.
