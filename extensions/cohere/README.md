# Omnipolymath Cohere Provider

Official Omnipolymath provider plugin for Cohere's OpenAI-compatible Compatibility
API.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/cohere-provider
omnipolymath gateway restart
```

Configure a Cohere API key, then select `cohere/command-a-plus-05-2026`,
`cohere/command-a-reasoning-08-2025`, `cohere/command-a-vision-07-2025`,
`cohere/command-a-03-2025`, or `cohere/north-mini-code-1-0`.
