# OpenCode Zen Omnipolymath provider

Official Omnipolymath provider plugin for the OpenCode Zen model catalog, image
understanding, and native OpenCode session browsing.

## Install

```sh
omnipolymath plugins install @omnipolymath/opencode-provider
omnipolymath gateway restart
```

## Docs

See `docs/providers/opencode.md` in the Omnipolymath repository, or the published
docs at `https://omnipolymath.vercel.app/docs/providers/opencode`.
