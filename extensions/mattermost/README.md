# Mattermost Omnipolymath channel

Official Omnipolymath channel plugin for Mattermost.

## Install

```sh
omnipolymath plugins install @omnipolymath/mattermost
```

## Docs

See `docs/channels/mattermost.md` in the Omnipolymath repository, or the published docs at `https://omnipolymath.vercel.app/docs/channels/mattermost`.
