# Omnipolymath Baseten Provider

Official Omnipolymath provider plugin for Baseten Model APIs, with DeepSeek V4.1 Flash as the starter model.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/baseten-provider
omnipolymath gateway restart
```

See <https://omnipolymath.vercel.app/docs/providers/baseten> for setup and configuration.
