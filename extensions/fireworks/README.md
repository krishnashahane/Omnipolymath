# Fireworks Omnipolymath provider

Official Omnipolymath provider plugin for Fireworks.

## Install

```sh
omnipolymath plugins install @omnipolymath/fireworks-provider
```

## Docs

See `docs/providers/fireworks.md` in the Omnipolymath repository, or the published docs at `https://omnipolymath.vercel.app/docs/providers/fireworks`.
