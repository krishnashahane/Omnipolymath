# Tencent Cloud Omnipolymath provider

Official Omnipolymath provider plugin for Tencent Cloud.

## Install

```sh
omnipolymath plugins install @omnipolymath/tencent-provider
```

## Docs

See `docs/providers/tencent.md` in the Omnipolymath repository, or the published docs at `https://omnipolymath.vercel.app/docs/providers/tencent`.
