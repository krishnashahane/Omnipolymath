# Omnipolymath Requesty Provider

Official Omnipolymath provider plugin for [Requesty](https://requesty.ai), an
OpenAI-compatible router for hundreds of models behind one API key. Discovery lists
the managed policies your key can route to, addressed by bare model name.

Requesty is bundled with Omnipolymath and releases together with the host. No separate
plugin installation is required.

Configure it through onboarding:

```bash
omnipolymath onboard --auth-choice requesty-api-key
```

See <https://omnipolymath.vercel.app/docs/providers/requesty> for setup and configuration.
