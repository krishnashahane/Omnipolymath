# Omnipolymath Voyage Provider

Official Omnipolymath memory embedding provider plugin for Voyage AI.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/voyage-provider
omnipolymath gateway restart
```

Set `VOYAGE_API_KEY`, then configure memory search with `provider: "voyage"`.
See <https://omnipolymath.vercel.app/docs/reference/memory-config> for setup and
configuration.
