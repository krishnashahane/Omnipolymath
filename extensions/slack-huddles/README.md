# Slack huddles

Join an active Slack huddle through a dedicated Slack user signed into the Omnipolymath Chrome profile. This plugin is disabled by default.

```bash
omnipolymath plugins install @omnipolymath/slack-huddles
omnipolymath plugins enable slack-huddles
```

See https://omnipolymath.vercel.app/docs/plugins/slack-huddles for setup, modes, audio routing, captions, and limitations.

- Plugin id: `slack-huddles`
- Tool: `slack_huddles`
- CLI: `slackhuddles`
- Package: `@omnipolymath/slack-huddles`
- Minimum Omnipolymath host: `2026.7.2`
