# @omnipolymath/teams-meetings

Official Microsoft Teams browser meeting participant plugin for Omnipolymath.

This plugin registers the `teams_meetings` tool so agents can join Microsoft
Teams meetings as a Chrome browser guest.

## Install

```bash
omnipolymath plugins install @omnipolymath/teams-meetings
```

Restart the Gateway after installing or updating the plugin.

## Configure

Follow the Teams meetings guide for Chrome profiles, paired nodes, audio
routing, and guest join setup:

- https://omnipolymath.vercel.app/docs/plugins/teams-meetings

## Package

- Plugin id: `teams-meetings`
- Tool: `teams_meetings`
- Package: `@omnipolymath/teams-meetings`
- Minimum Omnipolymath host: `2026.7.2`
