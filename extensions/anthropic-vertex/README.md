# Omnipolymath Anthropic Vertex Provider

Official Omnipolymath provider plugin for Claude models hosted through Google Vertex AI.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/anthropic-vertex-provider
```

Configure Google Cloud credentials and the target Vertex project/region in Omnipolymath, then select Claude models with the Anthropic Vertex provider.
