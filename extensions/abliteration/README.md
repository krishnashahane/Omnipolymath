# Omnipolymath Abliteration Provider

Official Omnipolymath provider plugin for Abliteration's OpenAI-compatible API.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/abliteration-provider
```

See <https://omnipolymath.vercel.app/docs/providers/abliteration> for setup and configuration.
