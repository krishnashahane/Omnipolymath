# Omnipolymath Volcengine Provider

Official Omnipolymath provider plugin for Volcengine models, the Volcengine coding
plan, and Volcengine Speech text-to-speech.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/volcengine-provider
omnipolymath gateway restart
```

See <https://omnipolymath.vercel.app/docs/providers/volcengine> for model and speech setup.
