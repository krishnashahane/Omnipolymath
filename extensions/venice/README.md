# Venice Omnipolymath provider

Official Omnipolymath provider plugin for Venice.

## Install

```sh
omnipolymath plugins install @omnipolymath/venice-provider
```

## Docs

See `docs/providers/venice.md` in the Omnipolymath repository, or the published docs at `https://omnipolymath.vercel.app/docs/providers/venice`.
