# Omnipolymath LongCat Provider

Official Omnipolymath provider plugin for LongCat-2.0 through LongCat's hosted
OpenAI-compatible API.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/longcat-provider
omnipolymath gateway restart
```

Configure `LONGCAT_API_KEY`, then select `longcat/LongCat-2.0`.
