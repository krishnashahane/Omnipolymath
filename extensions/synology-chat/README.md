# Omnipolymath Synology Chat

Official Omnipolymath channel plugin for Synology Chat conversations and direct messages.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/synology-chat
```

Configure Synology Chat credentials and allowed conversations in Omnipolymath, then use the plugin to route messages between Synology Chat and Omnipolymath agents.
