# Omnipolymath Feishu/Lark

Official Omnipolymath channel plugin for Feishu and Lark workplace chats. Community maintained by @m1heng.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/feishu
```

Configure the Feishu/Lark app credentials in Omnipolymath, then connect the plugin to the chats where agents should receive and send messages.
