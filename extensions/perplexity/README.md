# Omnipolymath Perplexity Plugin

Official Omnipolymath plugin for Perplexity.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/perplexity-plugin
omnipolymath gateway restart
```

See <https://omnipolymath.vercel.app/docs/tools/perplexity-search> for setup and configuration.
