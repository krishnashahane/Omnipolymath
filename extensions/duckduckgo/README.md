# Omnipolymath DuckDuckGo Plugin

Official Omnipolymath plugin for DuckDuckGo web search.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/duckduckgo-plugin
omnipolymath gateway restart
```

See <https://omnipolymath.vercel.app/docs/tools/duckduckgo-search> for setup and configuration.
