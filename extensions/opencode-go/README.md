# Omnipolymath OpenCode Go Provider

Official Omnipolymath provider plugin for the OpenCode Go model catalog.

OpenCode Go is bundled with Omnipolymath for this release; no separate plugin
installation is required.

Configure `OPENCODE_API_KEY` or `OPENCODE_ZEN_API_KEY`, then select an
`opencode-go/...` model.

See <https://omnipolymath.vercel.app/docs/providers/opencode-go> for setup and the current
model catalog.
