# SMS/MMS Omnipolymath channel

Official Omnipolymath channel plugin for Twilio SMS and MMS.

## Install

```sh
omnipolymath plugins install @omnipolymath/sms
```

## Docs

See `docs/channels/sms.md` in the Omnipolymath repository, or the published docs at `https://omnipolymath.vercel.app/docs/channels/sms`.
