# Omnipolymath Qianfan Provider

Official Omnipolymath provider plugin for Qianfan.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/qianfan-provider
omnipolymath gateway restart
```

See <https://omnipolymath.vercel.app/docs/providers/qianfan> for setup and configuration.
