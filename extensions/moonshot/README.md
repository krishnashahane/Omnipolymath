# Moonshot Omnipolymath provider

Official Omnipolymath provider plugin for Moonshot.

## Install

```sh
omnipolymath plugins install @omnipolymath/moonshot-provider
```

## Docs

See `docs/providers/moonshot.md` in the Omnipolymath repository, or the published docs at `https://omnipolymath.vercel.app/docs/providers/moonshot`.
