# Omnipolymath DeepInfra Provider

Official Omnipolymath provider plugin for DeepInfra.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/deepinfra-provider
omnipolymath gateway restart
```

See <https://omnipolymath.vercel.app/docs/providers/deepinfra> for setup and configuration.
