# Omnipolymath StepFun Provider

Official Omnipolymath provider plugin for StepFun.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/stepfun-provider
omnipolymath gateway restart
```

See <https://omnipolymath.vercel.app/docs/providers/stepfun> for setup and configuration.
