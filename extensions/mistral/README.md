# Omnipolymath Mistral Provider

Official Omnipolymath provider plugin for Mistral models, Voxtral transcription, and
Mistral memory embeddings.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/mistral-provider
omnipolymath gateway restart
```

Set `MISTRAL_API_KEY`, then select a `mistral/*` model or configure Mistral for
media transcription, realtime transcription, or memory embeddings.

See <https://omnipolymath.vercel.app/docs/providers/mistral> for setup and configuration.
