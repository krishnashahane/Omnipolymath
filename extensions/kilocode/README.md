# Omnipolymath Kilo Gateway Provider

Official Omnipolymath provider plugin for Kilo Gateway.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/kilocode-provider
omnipolymath gateway restart
```

See <https://omnipolymath.vercel.app/docs/providers/kilocode> for setup and configuration.
