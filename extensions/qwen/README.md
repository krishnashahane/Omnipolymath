# Omnipolymath Qwen Cloud Provider

Official Omnipolymath provider plugin for Qwen Cloud.

Install from Omnipolymath:

```bash
omnipolymath plugins install @omnipolymath/qwen-provider
omnipolymath gateway restart
```

See <https://omnipolymath.vercel.app/docs/providers/qwen> for setup and configuration.
