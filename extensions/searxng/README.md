# SearXNG Omnipolymath plugin

Official Omnipolymath plugin for SearXNG.

## Install

```sh
omnipolymath plugins install @omnipolymath/searxng-plugin
```

## Docs

See `docs/tools/searxng-search.md` in the Omnipolymath repository, or the published docs at `https://omnipolymath.vercel.app/docs/tools/searxng-search`.
