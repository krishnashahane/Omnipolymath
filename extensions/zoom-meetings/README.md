# @omnipolymath/zoom-meetings

Official Zoom browser meeting participant plugin for Omnipolymath.

This plugin registers the `zoom_meetings` tool so agents can join Zoom meetings
as a Chrome browser guest.

## Install

```bash
omnipolymath plugins install @omnipolymath/zoom-meetings
```

Restart the Gateway after installing or updating the plugin.

## Configure

Follow the Zoom meetings guide for Chrome profiles, paired nodes, audio routing,
and guest join setup:

- https://omnipolymath.vercel.app/docs/plugins/zoom-meetings

## Package

- Plugin id: `zoom-meetings`
- Tool: `zoom_meetings`
- Package: `@omnipolymath/zoom-meetings`
- Minimum Omnipolymath host: `2026.7.2`
