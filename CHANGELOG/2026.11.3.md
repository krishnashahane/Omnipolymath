## 2026.11.3

The first Omnipolymath release.

### Trust Firewall (on by default)

- **Approvals before risky actions.** Calls that spend money or can't be taken back (deleting files, force-pushing, dropping tables) wait for your approval. Per-agent tool allowlists keep each agent to the tools it needs.
- **Prompt-injection shield.** Every tool result is scanned for injection patterns. Content from web pages, email and chat also gets a second opinion from your own model. Once a run reads suspicious content, outbound and write actions in that run need your approval.
- **Undo.** Before `write`, `edit` or `apply_patch` changes a file, the firewall snapshots it. `omnipolymath firewall undo <run>` puts the files back, and skips any file someone edited afterwards unless you pass `--force`.
- **Tamper-evident action log.** Every decision is a hash-chained JSON line. `omnipolymath firewall verify` reports the exact entry if anything was edited, removed or reordered.
- **Daily spend cap.** Spend is priced from the cost your model provider reports for each response, with built-in list prices as a fallback, and survives gateway restarts.
- **Agent wallets.** Any tool that pays, charges or orders is held to a per-transaction and a daily USD limit, with an optional payee allowlist. Calls you deny are refunded to the wallet.
- **Receipts.** Every run ends with a receipt: what it did, what it cost, what changed, what was stopped, and how to undo it.

### Also new

- **Self-cleaning memory** (`fact_save`, `fact_search`): facts carry provenance and an integrity hash, decay over time, and resolve contradictions. Facts saved after reading suspicious content are kept at low confidence.
- **Skill install checks**: every skill is scanned for dangerous permissions when installed, and publisher signatures are verified. You can require signatures or block high-risk unsigned skills.
- **Signed handoffs**: `omnipolymath firewall handoff` issues and verifies Ed25519-signed, scoped, expiring delegations between agents.
- **No telemetry by default**: Omnipolymath sends no usage data or update checks anywhere unless you set `OMNIPOLYMATH_TELEMETRY_ENDPOINT`.
